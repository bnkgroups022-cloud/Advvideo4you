Frequently asked questions

Is it really free?

Yes. The notebook uses Colab's free T4 GPU. Google decides GPU availability and session limits for free accounts, so you may occasionally have to wait or try again later.

Do I need an account?

You need a Google account to use Colab. This website has no accounts, no uploads and no tracking of its own.

Where does my photo go?

Only into your own Colab session, where the notebook turns it into the first frame of the video. It is never sent to this website.

Which model does it use?

Wan2.1 VACE-1.3B, run through the official Wan-Video/Wan2.1 repository. Your photo becomes the first frame and the model generates the motion that follows.

How long is the video, and how long does it take?

The default is 49 frames, about 3 seconds at 16 fps. The first run also downloads roughly 19 GB of model files, so expect a longer wait then. You can raise the frame count in the notebook's form field at the top of the cell.

What if it runs out of memory?

The notebook retries automatically with a shorter clip (33, then 17 frames), so you do not have to change anything.

Can I use the videos commercially?

Check the license of the Wan2.1 model in its official repository before using the output commercially. This project only provides the notebook.

Start free in 5 steps

Everything runs in your own Google Colab session.

  1. Google Colab account required

    Sign in with any Google account when Colab asks. Colab and its T4 GPU are free.

  2. Use Runtime → Change runtime type

    Open the Runtime menu at the top of the notebook.

    Runtime → Change runtime type

  3. Select GPU → T4

    Choose the T4 GPU as the hardware accelerator, then press Save.

    Hardware accelerator → T4 GPU → Save

  4. Click Runtime → Run all

    This starts everything. The shortcut is Ctrl+F9 (Cmd+F9 on Mac).

    Runtime → Run all

  5. Upload one product photo

    When the Choose Files button appears under the cell, pick one JPG or PNG photo. output.mp4 then downloads automatically when generation finishes.
