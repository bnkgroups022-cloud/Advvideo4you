Advvideo4you

Turn one product photo into a 9:16 vertical ad video. The generator is a single Google Colab notebook that runs on the free T4 GPU.

  • Model: Wan2.1 VACE-1.3B, run through the official Wan-Video/Wan2.1 repository
  • Output: 480x832 MP4, downloaded automatically
  • One image upload, then Runtime → Run all
